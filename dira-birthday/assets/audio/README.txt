BIRTHDAY SONG

The supplied birthday song is intended to be stored at:

    assets/audio/happy-birthday-song.mp3

The page's Play birthday song button uses this file. Playback starts only when Dira taps the button; it does not autoplay.

The MP3 is included in the downloadable Dira-Birthday project ZIP. Upload that MP3 into this folder in the public GitHub repository to activate the music control on GitHub Pages.

Before publishing it publicly, make sure you have permission to share the recording.
