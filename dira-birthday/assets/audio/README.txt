BIRTHDAY SONG

The supplied birthday song is included in the downloadable project package at:

    assets/audio/happy-birthday-song.mp3

The page's Play birthday song button uses this file. Playback starts only when Dira taps the button; it does not autoplay.

For the public GitHub Pages copy, the song is also stored as 13 small text assets in:

    assets/audio/data/song-01.txt through song-13.txt

The page can rebuild and play the song from those text assets if the MP3 binary is not available.

Before publishing it publicly, make sure you have permission to share the recording.
